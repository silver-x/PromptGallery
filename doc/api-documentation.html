PromptGallery API 接口文档

完整的 API 接口说明文档，包含所有模块的详细接口信息

用户认证 API

用户认证模块提供用户注册、登录、密码管理等核心认证功能。

基础信息

  • 基础URL: /api/v1/auth
  • 认证方式: JWT Token
  • 内容类型: application/json
POST /register
用户注册新账户

请求参数

参数名 类型 必填 说明
username string 是 用户名，3-50字符，唯一
email string 是 邮箱地址，唯一
password string 是 密码，8-50字符
nickname string 否 昵称，1-100字符
captcha string 是 验证码

响应示例

JSON
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "user_id": 12345,
    "username": "testuser",
    "email": "test@example.com",
    "nickname": "测试用户",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expires_in": 86400
  }
}
POST /login
用户登录获取访问令牌

请求参数

参数名 类型 必填 说明
login string 是 用户名或邮箱
password string 是 密码
remember_me boolean 否 是否记住登录状态
captcha string 否 验证码
POST /refresh
使用刷新令牌获取新的访问令牌
POST /logout
用户登出，使令牌失效
POST /forgot-password
发送密码重置邮件
POST /reset-password
使用重置令牌重置密码
POST /change-password
用户修改密码
GET /verify
验证访问令牌是否有效
GET /captcha
获取图形验证码

错误码说明

错误码 说明
400请求参数错误
401未授权访问
403禁止访问
404资源不存在
409资源冲突（如用户名已存在）
422参数验证失败
429请求过于频繁
500服务器内部错误

注意事项

  1. 密码安全: 密码需要包含大小写字母、数字和特殊字符，长度8-50字符
  2. 令牌过期: 访问令牌默认24小时过期，刷新令牌30天过期
  3. 频率限制: 登录接口限制每分钟5次尝试，注册接口限制每小时3次
  4. 验证码: 连续登录失败3次后需要验证码
  5. 邮箱验证: 注册后需要验证邮箱才能完全激活账户

用户管理 API

用户管理模块提供用户信息管理、关注关系、个人资料等功能。

基础信息

  • 基础URL: /api/v1/users
  • 认证方式: JWT Token
  • 内容类型: application/json
GET /me
获取当前登录用户的详细信息
PUT /me
更新当前用户的个人信息
GET /{user_id}
获取指定用户的公开信息
POST /{user_id}/follow
关注指定用户
DELETE /{user_id}/follow
取消关注指定用户
GET /{user_id}/following
获取用户关注的人员列表
GET /{user_id}/followers
获取用户的粉丝列表
GET /{user_id}/prompts
获取用户发布的Prompt列表
GET /search
搜索用户
POST /me/avatar
上传用户头像
GET /{user_id}/stats
获取用户的统计信息

注意事项

  1. 隐私保护: 用户邮箱等敏感信息只有本人可见
  2. 关注限制: 每个用户最多可关注1000个用户
  3. 头像规格: 头像文件最大2MB，推荐尺寸200x200像素
  4. 频率限制: 关注/取消关注操作限制每分钟10次
  5. 数据缓存: 用户统计数据可能有5分钟延迟
  6. 账户状态: 被封禁用户的公开信息将不可访问

Prompt内容 API

Prompt内容模块提供Prompt的创建、编辑、删除、搜索、分类管理等核心功能。

基础信息

  • 基础URL: /api/v1/prompts
  • 认证方式: JWT Token（部分接口需要）
  • 内容类型: application/json
GET /
获取Prompt列表，支持多种筛选和排序
GET /{prompt_id}
获取指定Prompt的详细信息
POST /
创建新的Prompt
PUT /{prompt_id}
更新指定的Prompt
DELETE /{prompt_id}
删除指定的Prompt
POST /{prompt_id}/publish
发布Prompt（从草稿状态变为已发布）
POST /{prompt_id}/copy
复制Prompt内容（增加复制计数）
GET /search
全文搜索Prompt
GET /categories
获取所有分类列表
GET /tags
获取标签列表
GET /ai-models
获取支持的AI模型列表
POST /upload-image
上传Prompt预览图

注意事项

  1. 内容审核: 发布的Prompt需要通过内容审核
  2. 版权保护: 禁止上传侵犯版权的内容
  3. 质量评分: 系统会根据用户反馈自动计算质量评分
  4. 搜索优化: 标题和描述会被索引用于搜索
  5. 图片规格: 预览图推荐尺寸16:9，最大5MB
  6. 标签限制: 每个Prompt最多可添加10个标签
  7. 价格设置: 付费Prompt价格范围0.99-99.99
  8. 频率限制: 创建Prompt限制每小时10个

社区互动 API

社区互动模块提供点赞、收藏、评论、收藏夹管理等社区功能。

基础信息

  • 基础URL: /api/v1/community
  • 认证方式: JWT Token
  • 内容类型: application/json
POST /likes/prompts/{prompt_id}
对指定Prompt进行点赞
DELETE /likes/prompts/{prompt_id}
取消对指定Prompt的点赞
POST /likes/comments/{comment_id}
对指定评论进行点赞
DELETE /likes/comments/{comment_id}
取消对指定评论的点赞
POST /favorites
收藏指定Prompt到收藏夹
DELETE /favorites/{prompt_id}
取消收藏指定Prompt
GET /favorites
获取当前用户的收藏列表
GET /folders
收藏夹管理相关接口

相关接口

  • POST /folders - 创建收藏夹
  • GET /folders - 获取收藏夹列表
  • PUT /folders/{folder_id} - 更新收藏夹
  • DELETE /folders/{folder_id} - 删除收藏夹
GET /comments
评论管理相关接口

相关接口

  • POST /comments - 发表评论
  • GET /comments - 获取评论列表
  • PUT /comments/{comment_id} - 更新评论
  • DELETE /comments/{comment_id} - 删除评论
GET /feed
获取关注用户的最新动态
GET /trending
获取热门Prompt和评论

注意事项

  1. 防刷机制: 点赞、评论等操作有频率限制
  2. 内容审核: 评论内容需要通过审核才能显示
  3. 收藏夹限制: 每个用户最多可创建50个收藏夹
  4. 评论嵌套: 评论最多支持3层嵌套回复
  5. 敏感词过滤: 评论内容会进行敏感词检测
  6. 举报机制: 用户可以举报不当评论
  7. 数据缓存: 点赞数、评论数等统计数据可能有延迟
  8. 权限控制: 只能操作自己的评论和收藏

基础信息

  • 基础URL: /api/v1/transactions
  • 认证方式: JWT Token
  • 内容类型: application/json

相关接口

  • POST /orders/{order_id}/cancel - 取消订单

支付处理相关接口

相关接口

  • POST /payments - 发起支付
  • GET /payments/{payment_id}/status - 查询支付状态
  • POST /payments/notify - 支付回调处理

钱包管理相关接口

相关接口

  • GET /wallet - 获取钱包信息
  • GET /wallet/transactions - 获取钱包流水
  • POST /wallet/withdraw - 申请提现
  • GET /wallet/withdraw-history - 获取提现记录
POST /refunds
退款处理相关接口

相关接口

  • POST /refunds - 申请退款
  • GET /refunds/{refund_id} - 获取退款详情
  • GET /refunds - 获取退款列表
  • POST /refunds/{refund_id}/approve - 审批退款
GET /earnings
收益统计相关接口

相关接口

  • GET /earnings - 获取收益统计
  • GET /earnings/daily - 获取每日收益
  • GET /earnings/monthly - 获取月度收益
  • GET /earnings/reports - 生成收益报告

注意事项

  1. 支付安全: 所有支付接口都使用HTTPS加密传输
  2. 订单状态: 订单状态包括待支付、已支付、已完成、已取消、已退款
  3. 支付方式: 支持支付宝、微信支付、银行卡等多种支付方式
  4. 手续费: 平台收取交易金额的5%作为手续费
  5. 提现规则: 最低提现金额10元，工作日1-3天到账
  6. 退款政策: 购买后7天内可申请退款
  7. 发票服务: 支持开具电子发票
  8. 风控系统: 异常交易会被风控系统拦截
